# 🏏 IPL 2025 Power BI Dashboard

This repository showcases a dynamic and interactive Power BI dashboard built using real-time data fetched through API integration. The dashboard visualizes key statistics, player performances, team standings, and match insights for the TATA IPL 2025 season.

## 🔗 Live Data Integration

This project leverages API connectivity to pull IPL data dynamically into Power BI, enabling:
- 🟢 Live match updates (results, fixtures, current scores)
- 📋 Updated player statistics and squad info
- 📈 Real-time points table tracking

## 📊 Project Features

- 🏠 **Home Page**: Features top IPL team captains with a custom visual theme.
- 🔍 **Overview Page**: Displays live results, fixtures, player records, and schedules.
- 📈 **Points Table**: Automatically updated via API with team performance stats.
- 🧑‍🤝‍🧑 **Squads Page**: Lists all players with roles, teams, age, and visuals.

## 🧠 Achievements & Value

- ✅ **Real-Time Analytics** using API-connected data sources.
- ✅ **Drill-down functionality** for team-wise and player-wise insights.
- ✅ **Professional Layout** for a seamless user experience.
- ✅ **Business Value**: Enables franchises and analysts to monitor trends, key players, and live standings.

## 📂 Dataset & API Source

Data is fetched from a custom-built API tailored for IPL 2025 statistics simulation.  
(*Note: The dataset is repurposed from public sources and API endpoints for academic demonstration purposes.*)
